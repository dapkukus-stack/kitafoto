# KitaFoto Sound Assets

File audio yang perlu diganti dengan file asli sebelum build:

| File | Deskripsi | Durasi | Tips |
|------|-----------|--------|------|
| `countdown-beep.mp3` | Suara beep tiap detik countdown | ~0.3 detik | Suara "ding" atau "pop" lucu |
| `countdown-go.mp3` | Suara "GO!" saat countdown habis | ~0.5 detik | Suara "yay!" atau "cheese!" |
| `shutter.mp3` | Suara klik kamera | ~0.2 detik | Classic camera shutter |
| `print-done.mp3` | Suara selesai print | ~1 detik | Jingle pendek menyenangkan |
| `success-jingle.mp3` | Jingle selesai sesi | ~2 detik | Happy tune anak-anak |
| `ambience-fun.mp3` | Musik background | ~60 detik (loop) | Musik fun ringan tanpa vokal |

## Rekomendasi Free Resources
- https://freesound.org — Gratis dengan lisensi CC
- https://zapsplat.com — Free tier tersedia
- https://pixabay.com/music — Royalty-free music

## Format
- Format: MP3
- Sample rate: 44100 Hz
- Bit rate: 128 kbps (cukup untuk SFX)
- Volume: normalize ke -3dB
