# KitaFoto Font Assets

Font **Nunito** diperlukan untuk tampilan child-friendly KitaFoto.

## Download Nunito Font

1. Buka: https://fonts.google.com/specimen/Nunito
2. Download family (pilih semua weight)
3. Extract dan copy file berikut ke folder ini:
   - `Nunito-Regular.ttf`
   - `Nunito-SemiBold.ttf`
   - `Nunito-Bold.ttf`
   - `Nunito-ExtraBold.ttf`
   - `Nunito-Black.ttf`

## Lisensi
Nunito adalah font open source dengan lisensi SIL Open Font License 1.1
Aman digunakan untuk produk komersial.
